**Cursor**

저장되는 결과는 **문서에서 탐지된 오류 목록(findings)** 입니다.  
형식은 JSON과 CSV 두 가지로 저장되고, 파일명은 업로드 원본 기준입니다.

- 저장 위치: `outputs/`
- 파일명 예시: `원본파일명_findings.json`, `원본파일명_findings.csv`

저장 항목(한 건당):
- `page`: 페이지 번호 (`pdf`는 실제 페이지, `docx/hwpx`는 가상 페이지)
- `lang`: 문장 언어 (`ko`, `en` 등)
- `category`: 오류 유형 (예: `spacing`, `punctuation`, 문법 카테고리 등)
- `message`: 오류 설명
- `sentence`: 문제 문장
- `prev_sentence`: 이전 문장
- `next_sentence`: 다음 문장
- `suggestions`: 수정 제안 목록
- `span`: 문장 내 위치 정보 (`offset`, `length`)

참고로 CSV에서는
- `suggestions`는 `;`로 이어진 문자열,
- `span`은 JSON 문자열 형태로 들어갑니다.
